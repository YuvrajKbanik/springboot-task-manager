# Spring Boot Task Manager

A CRUD Task Manager built using:

- Spring Boot
- Spring Data JPA
- Thymeleaf
- MySQL
- Maven

## Features

- Add Task
- Edit Task
- Delete Task
- View Tasks

## Technologies

- Java 17
- Spring Boot
- MySQL
- Thymeleaf

## Run

git clone <repository-url>

Import into IntelliJ

Run StoreApplication.java
